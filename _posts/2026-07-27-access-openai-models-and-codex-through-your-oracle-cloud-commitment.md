## What it is
OpenAI models and Codex are now accessible directly through Oracle Cloud. This enables organizations to build and deploy OpenAI-powered applications using their existing Oracle Cloud spend commitments.

## Business use case
Enterprise IT procurement and engineering teams can deploy OpenAI models and Codex within Oracle Cloud. This allows organizations to leverage existing cloud budgets and governance frameworks to build AI applications without managing separate vendor commitments.

## Estimated value
Financial value is uncertain and dependent on enterprise cloud spend, but it qualitatively reduces procurement friction and optimizes cloud budget utilization by applying existing Oracle commitments toward OpenAI services.

## Implementation
Requires an Oracle Cloud account with existing spend commitments and setting up OpenAI model and Codex access within the Oracle Cloud environment using its governance and security controls.

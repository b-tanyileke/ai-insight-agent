## What it is
Claude Opus 5 is an AI model from Anthropic that provides near-frontier intelligence at half the price of Claude Fable 5, featuring customizable effort settings to optimize for either speed/cost or performance.

## Business use case
Software engineers, business process automation teams, and scientific researchers can deploy it for end-to-end coding tasks, computer-use automation, bug fixing, and scientific analysis such as organic chemistry structure inference.

## Estimated value
Offers higher task performance at a lower cost, achieving more than double the benchmark performance of Opus 4.8 on software tasks and performing near Fable 5 levels at half the cost per task.

## Implementation
Requires accessing the model as the default option on Claude Max or Claude Pro, or integrating it via API while configuring the desired effort setting based on task requirements.
